
# 🔍 Event Detection Using ML Models 🚀  

## 📌 Project Overview  
This project focuses on **event detection** from news articles using **Machine Learning models**. We utilize **TF-IDF and Count Vectorizer** to extract features and classify events into categories:  
🎭 **Entertainment** | 🏛️ **Politics** | 💼 **Business** | 🔧 **Tech** | ⚽ **Sports**  

With various **ML models**, we aim to achieve **high accuracy** in detecting and categorizing news events.  

---

## ⚡ Model Performance  

| 🌲 Random Forest               | **98%** (Best)   

✅ **Key Takeaways:**  
- **Random Forest** achieved the highest accuracy of **98%**, making it the best-performing model.  
- Feature extraction using **TF-IDF and Count Vectorizer** played a crucial role in classification.  
- Other models also performed well, but Random Forest outshined in event detection.  

---

## 🏗️ Models Used  
- 🔹 **Logistic Regression** – A simple yet effective linear model.  
- 🌲 **Random Forest** – The best performer with high accuracy.  
- 📊 **Multinomial Naive Bayes** – Strong for text classification tasks.  
- ⚖️ **Support Vector Classifier** – Effective for high-dimensional data.  
- 🌳 **Decision Tree** – Good interpretability but prone to overfitting.  
- 🔍 **K-Nearest Neighbors** – Lazy learning but useful in some cases.  
- 📈 **Gaussian Naive Bayes** – Probabilistic model assuming normal distribution.  

---

## 📊 Dataset  
The dataset consists of **news articles** labeled into five event categories:  
🎭 **Entertainment** | 🏛️ **Politics** | 💼 **Business** | 🔧 **Tech** | ⚽ **Sports**  

We process and clean the text data before applying **TF-IDF and Count Vectorizer** for feature extraction.
